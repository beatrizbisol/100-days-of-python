# 100 Days of Python

Personal notes and solutions from [100 Days of Code: The Complete Python Pro Bootcamp](https://www.udemy.com/share/103IHM3@EVcId42GR0fTE1kcLkHNeZLaiaoZvjteUiEdNQHgdGvF0VS7_fPQpnvHvJST0Q9i/).

Days 1–15 are completed in PyCharm with the JetBrains Academy course project. This repo stores the explanations and working solutions in Markdown.

## Course

- **Course:** 100 Days of Code — The Complete Python Pro Bootcamp
- **Link:** [Udemy (share link)](https://www.udemy.com/share/103IHM3@EVcId42GR0fTE1kcLkHNeZLaiaoZvjteUiEdNQHgdGvF0VS7_fPQpnvHvJST0Q9i/)

## How notes are organized

Notes are grouped by course level. Beginner lessons (Days 1–15) live in `Beginner/`. Each day is a Markdown file named after the lesson, for example `Beginner/Day 1.md`.

Typical structure:

- **Content** — syntax and concepts from that day
- **Exercise** — the prompt from the course
- **Solution** — code that ran successfully in PyCharm

## Setup

Python 3.14 (from [python.org](https://www.python.org/downloads/)) and [PyCharm](https://www.jetbrains.com/pycharm/download/) are used for this course.

```bash
python3 -m venv .venv
source .venv/bin/activate
```
