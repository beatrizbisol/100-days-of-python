# 100 Days of Python

Repositório dos exercícios do curso de Python.

Cada pasta `day-XX` corresponde a um dia do curso.

## Como usar

1. Crie (ou ative) um ambiente virtual:

```bash
python3 -m venv .venv
source .venv/bin/activate
```

2. Entre na pasta do dia e rode o arquivo:

```bash
python day-01/hello.py
```

## Estrutura

```
100-days-of-python/
├── day-01/
│   └── hello.py
└── README.md
```
